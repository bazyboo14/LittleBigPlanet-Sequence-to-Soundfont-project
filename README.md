# LittleBigPlanet-Sequence-to-Soundfont-project
This project is meant to contain some sound fonts that use the same samples as the Music Sequencer Instruments, thus converting Sequencer to Soundfont
this is a heavy WIP and I'll be trying to add as many Soundfonts as needed to this.
## How to use:
- each Soundfont is organized the same way they are in the files of LittleBigPlanet (ex: all Baiyon sounds are in Baiyon.SF2 and each individual instrument is a patch or preset in the .SF2 file)
- each patch starts at A-1 for their lowest note and each octave is a different sample from the instrument
